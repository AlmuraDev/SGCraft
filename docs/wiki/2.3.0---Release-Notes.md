- Complete new rendering for Milky Way, Atlantis and Universe gates
- Added Supergates, including Ori
- Added Asgard Transportation Obelisk
- Added Transportation Rings
- Added Naquadah Generators (Mark I, Mark II)
- Added Zat weapon
- Added City Shield Generator
- Added EDD (Exploration Dialing Device)
- Added Atlantis Shield to the gate feature
- Added tons of features to Personal Dialing Devices
- Added tons of features to the Configurator device, fixed Access permissions issues
- Added EnderIO support
- Added random Address Books to loot tables
- Added backwards compatibility for ZPM power systems to Forge hooks
- Fixed many issues with internal code layouts, rendering issues etc.
- Fixed CollisionBox issues with ZPM Cart
- GDO now renders gates visually with their iris states
- Fixed event horizon rendering in front of iris
- Gates now emit light when connected
- Fixed issue with dialing, chevrons now are in sync
- Changed dialing visuals and locking procedures for Milky Way and Atlantis gates, matches Lore
- Fixed loot tables, added configurable loot tables, fixed ability to not be able to modify loot tables
- Fixed issue with GUIs causing a client side crash due to packets being on the wrong thread
- Fixed transparency issue of address while displayed on PDD
- Added ability to move items around easily on PDD without manually editing index value
- Added function where if you're standing at a gate whose address is in your PDD, the item is greyed out and you cannot select it, but you can still move it around or edit it
- Fixed horizontal gates
- Added Creative Menu blocks to auto-build a gate of a specific type
- Fixed gate generation issues with World Gen
- Fixed Naquadah Ore generation

# SGCraft

SGCraft adds working Stargates to Minecraft 1.12.2 (Forge): build a gate, dial another world or another gate across
the map, and step through the event horizon. Around the gates are the things that go with them: DHDs and hand
dialers, irises and shields, Zero Point Modules, transport rings, Asgard obelisks, a city shield and a Zat.

## Requirements

| Mod | Needed for |
|---|---|
| Forge 14.23.5.2838+ | everything |
| MalisisCore 6.6 | the PDD, EDD, GDO, Configurator, Shield Console, City Shield and Naquadah Generators |
| SpongeForge (optional) | permission nodes; without it every `sgcraft.*` permission is granted |
| IndustrialCraft 2 (optional) | the IC2 Stargate Power Unit and EU output from ZPM carts and hubs |
| ComputerCraft / OpenComputers (optional) | the computer interface blocks |
| Dynmap (optional) | stargate markers on the web map |

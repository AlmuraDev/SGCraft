# Block of Naquadah Alloy

The Block of Naquadah Alloy is nine naquadah alloy ingots in one block. It stores ingots and goes into the supergate recipes.

```infobox
Block of Naquadah Alloy
ID: sgcraft:naquadah_block
Category: Materials
Type: Block
Stackable: Yes (64)
Tool: Pickaxe
Tool tier: Iron or better
Hardness: 5
Blast resistance: 6
Waterloggable: No
Drops: Itself
Block entity: No
```

## Obtaining

### Crafting

```recipe
sgcraft:naquadah_block
```

## Usage

- Nine {{item:sgcraft:naquadah_ingot}} craft into one block for storage, and the block crafts back into nine ingots.
- Craft blocks into a {{item:sgcraft:supergate_ring}} or a {{item:sgcraft:supergate_base}}. See [Building gates](../building-gates.md#supergates).

```recipe
sgcraft:naquadah_ingot_from_block
```

Mine the block with an iron pickaxe or better. A weaker pickaxe or any other tool drops nothing. A block destroyed by an explosion may not drop.
